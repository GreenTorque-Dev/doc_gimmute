# Backup Solution – Security & Protection Features

## Strong Ransomware Protection (Immutability)
- Protect backups from deletion or modification  
- Set time-based retention (keep backups for days)  
- Set count-based retention (keep last N backups)  
- Choose flexible backup intervals (minutes to days)  
- Enable or disable retention anytime  

### Dual-layer Immutability
- Soft lock (temporary protection)  
- Hard lock (strict, non-bypassable protection)  

## Multi-Factor Security (MFA)
- One-time password (OTP) required for sensitive actions  
- MFA required to:
  - Delete backups  
  - Change retention settings  
  - Enable or disable secondary copies  
- Prevents accidental or malicious deletion  

## Secondary Copy (Air-Gap Protection)
- Create additional backup copies automatically  
- Store secondary copies separately for extra safety  
- Schedule copies: Daily / Weekly / Monthly / Custom  
- Run secondary copy manually  
- View size and location  
- Delete securely with MFA
