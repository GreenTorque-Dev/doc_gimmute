# Backup Solution – System & Access Control Features

## User & Access Control
- Individual usernames for each backup location  
- Secure password-based access  
- Control which user can access which backup  
- Safe removal of users without risking data loss  

## System Control (Appliance-Style)
- Restart backup system from the UI  
- Shut down system safely  
- Designed for on-prem or private deployments  

## Built-in Network Security
- Control which IPs and ports can access the system  
- Enable or disable firewall with one click  
- Add or remove access rules easily  
- Reset or reload firewall rules when required
