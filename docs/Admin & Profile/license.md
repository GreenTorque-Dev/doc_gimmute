# License

## Overview

The License page allows administrators to activate and manage the G-Immute product license. A valid license is required for the system to function fully. When the license expires, a red banner reading **"Your license has expired. Renew license"** appears at the top of every page across the entire G-Immute interface until a new license is activated.

To access this page, click on **LICENSE** from the left navigation menu.

---

## License Page

![License page showing license key, status, and expiry](/img/license-page.png)

*Figure 59 — License page showing license key, status, and expiry*

| Element | Description |
|---|---|
| **License expired banner (Red)** | "Your license has expired. Renew license" — this red banner appears at the top of every page when the license is expired or invalid. Click **Renew license** to go directly to the License page. |
| **License Key field** | Enter your license key to activate or renew. The key is partially masked for security. Example: `E4F3****...****90BD` |
| **Activate button** | Click to activate the entered license key. The system will validate the key and update the license status. |
| **Status: Valid** | Confirms the license key has been successfully activated and is recognized by the system. |
| **EXPIRY DATE** | Shows the date when the current license will expire. Example: `JAN. 1, 1970` (shown in blue). Contact G-Immute support to obtain a new license key before the expiry date. |

:::note
When the license expires, a red banner will appear on every page of the G-Immute interface. To restore full system functionality, enter a new valid license key on this page and click **Activate**.
:::
